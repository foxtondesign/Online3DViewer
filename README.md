# Foxtondesign 3D Viewer

**Foxtondesign 3D Viewer** is a customized version of the [Online 3D Viewer](https://github.com/kovacsv/Online3DViewer), tailored specifically for visualizing and exploring 3D models in your browser. This solution is seamlessly integrated into my workflow to provide customers and clients with an enhanced viewing experience for project files.

## Purpose
This viewer is designed to:
- Offer a seamless way to preview 3D models for prospective buyers.
- Provide additional support for customers during assembly and construction phases by enabling them to view detailed 3D models of the projects they’ve purchased.

## Features
- **Custom Toolbar:** Simplified interface with unnecessary buttons removed (e.g., file upload and URL loading).
- **Restrictive Loading:** Only supports pre-defined project file links, ensuring a controlled and personalized experience.
- **STEP File Viewing:** Optimized for viewing STEP files hosted on Google Drive or similar platforms.

## How to Use
1. Open the viewer using the provided links for your purchased project.
2. View the 3D model directly in your browser.
3. (Optional) Access additional project details and purchase files via my [Payhip store](#).

## Supported File Formats
- **Import:** STEP, STL, OBJ, and more.
- **Export:** Not applicable—export functionality is disabled in this customized version.
